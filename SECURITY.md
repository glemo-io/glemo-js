# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, report them privately through GitHub's
[private vulnerability reporting](https://github.com/glemo-io/glemo-js/security/advisories/new),
or email security@glemo.io.

Include a description of the issue, the affected package and version, and steps to reproduce.
We aim to acknowledge reports within 48 hours and to keep you updated as we work on a fix.

## Supported versions

Security fixes land on the latest published minor of each package. Please upgrade to the latest
version before reporting.
